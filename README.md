# 连续回怼（AstrBot 插件）

通过群聊指令启动连续回怼任务，插件会从内置第二人称辛辣语料中随机抽取，逐条提及并回复目标成员；收到停止指令或达到数量上限后结束。任务成功启动时不额外发送确认消息。

- 插件名：`astrbot_plugin_retort_barrage`
- 版本：`1.2.0`
- 创作者：小星萤
- AstrBot：`>=4.16,<5`
- 平台：`aiocqhttp`（QQ）

## 指令

```text
/怼他 @某人   开始连续回怼
/停止怼       停止当前群的任务
/怼状态       查看当前群是否有任务
```

每个群同一时间只运行一个任务。插件停用或重载时会自动取消全部后台任务。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `send_interval` | `5.0` | 每条之间的秒数，代码强制不低于 3 秒 |
| `max_messages` | `20` | 单次条数上限，范围 1—60 |
| `avoid_duplicates` | `true` | 单次任务内尽量避免重复 |
| `mention_target` | `true` | 每条消息是否提及目标 |
| `announce_completion` | `true` | 达到上限后是否提示结束 |
| `aggressive_enabled` | `false` | 启用激进语料池（28 条更激烈的嘴臭/家人梗语句），默认关闭 |

以上配置可在 AstrBot WebUI 的插件配置页面修改，修改后请重载插件。

## 安装

将整个目录放入 AstrBot 的 `data/plugins/`，然后在 WebUI 插件管理中重载或启用插件。本插件仅使用 Python 标准库，没有额外依赖。

## 语料边界

内置语料保持高辛辣度，但不包含暴力威胁、歧视性攻击、隐私曝光或自伤诱导。语料分为两个池：默认的 `RETORTS`（169 条，不含家人攻击）和 `RETORTS_SPICY`（28 条激进语句，含更激烈的嘴臭与家人梗，默认关闭）。需要调整语料时，可编辑 `main.py` 中的对应元组并重载插件。
