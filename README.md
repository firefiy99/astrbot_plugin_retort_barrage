# 连续回怼（AstrBot 插件）

通过群聊指令启动连续回怼任务，插件从内置第二人称辛辣语料中随机抽取，逐条提及并回复目标成员；支持多目标轮流怼、主题筛选、被怼者求饶自动停止、表情包穿插与战绩统计，并内置黑名单、白名单、冷却、每日限额、敏感词过滤与风控熔断等多重保护。

- 插件名：`astrbot_plugin_retort_barrage`
- 版本：`2.0.0`
- 创作者：小星萤
- AstrBot：`>=4.16,<5`
- 平台：`aiocqhttp`（QQ）

## 指令

```text
/怼他 @某人 [主题]   开始连续回怼，可同时 @多人轮流怼
/停止怼             停止当前群的任务（任何人可用）
/怼状态             查看当前群任务进度
/怼统计             查看累计战绩与被怼榜
/怼帮助             查看使用说明与免责声明摘要
```

可选主题：`智力`、`外貌`、`家人`、`存在`、`言行`、`自定义`（默认全部随机）。其中 `家人` 主题仅存在于激进语料池，需开启 `aggressive_enabled` 或 `aggressive_only` 后才有内容。

每个群同一时间只运行一个任务。插件停用或重载时会自动取消全部后台任务。被怼目标发送求饶关键词（默认「我错了 / 我服了 / 别怼了 / 投降 / 饶了我」）会自动停止本群任务。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `send_interval` | `5.0` | 每条之间的秒数，代码强制不低于 3 秒 |
| `max_messages` | `20` | 单次条数上限，范围 1—60 |
| `avoid_duplicates` | `true` | 单次任务内尽量避免重复 |
| `mention_target` | `true` | 每条消息是否提及目标 |
| `announce_completion` | `true` | 达到上限后是否提示结束 |
| `aggressive_enabled` | `false` | 启用激进语料池（100 条更激烈的嘴臭/家人梗语句），与普通池混抽 |
| `aggressive_only` | `false` | 纯辛辣模式：仅从激进语料池随机发送（独立生效） |
| `target_blacklist` | `[]` | 保护名单：不可被怼的 QQ 号 |
| `starter_whitelist` | `[]` | 发起白名单：允许使用 `/怼他` 的 QQ 号，留空不限制 |
| `group_cooldown` | `0` | 同群两次任务的冷却秒数（自上次任务结束起算），0 不限制 |
| `daily_start_limit` | `0` | 每人每日发起次数上限，0 不限制 |
| `surrender_enabled` | `true` | 被怼者发送求饶关键词后自动停止任务 |
| `surrender_keywords` | `[]` | 求饶关键词，留空使用默认值 |
| `blocked_keywords` | `[]` | 敏感词过滤：包含任一关键词的语料不会被发送 |
| `image_probability` | `0` | 表情包穿插概率（0—100%），需配置 `image_urls` |
| `image_urls` | `[]` | 表情包图片 http(s) 地址，命中概率时随机发送一张 |

以上配置可在 AstrBot WebUI 的插件配置页面修改，修改后请重载插件。

## 语料结构

内置语料外置于 `corpus.json`，分为两个池，每条语句均标注主题（智力 / 外貌 / 家人 / 存在 / 言行）：

- `retorts`：普通池，167 条，不含家人攻击
- `retorts_spicy`：激进池，100 条，含更激烈的嘴臭与家人梗，默认关闭

自定义语料：编辑插件目录下的 `custom_retorts.txt`，每行一条；`#` 开头为注释；`!` 开头的行进入激进池，其余进入普通池，主题均为「自定义」。修改后重载插件生效。

战绩统计持久化于插件目录的 `stats.json`（运行时生成，已被 .gitignore 忽略）。

## 风控与保护

- 保护名单 `target_blacklist`：名单内成员不可被怼（建议放群主、管理员、自己人）
- 发起白名单 `starter_whitelist`：留空时所有人可发起
- 同群冷却 `group_cooldown` 与每日发起限额 `daily_start_limit`：防刷屏滥用
- 敏感词过滤 `blocked_keywords`：命中的语料（含自定义语料）不会发送
- 风控熔断：单次任务连续发送失败 3 次自动停止；10 分钟内熔断 3 次将暂停新任务 10 分钟

## 安装

将整个目录放入 AstrBot 的 `data/plugins/`，然后在 WebUI 插件管理中重载或启用插件。本插件仅使用 Python 标准库，没有额外依赖。
